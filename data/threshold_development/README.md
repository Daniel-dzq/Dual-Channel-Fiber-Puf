# Threshold-development data

The acquisition comprises 15 devices, three mechanical states and eight challenges in
Round A and Round B, with one red identity recording per device–state unit.
The dataset provides the recording manifest, valid-pixel mask and response data.
Run the raw analysis before evaluating `scripts/reproduce_threshold_development.py`.
The validation targets are T_R = −1.748, T_G = 0.134 and n_req = 6, as specified in
Supplementary Note 7.1. A failed comparison blocks release; values are never adjusted
by the validation script.
