# Figure map

Every `scripts/reproduce_*.py` script reads the public dataset (`--data-root`, or
`$PUF_DATA_ROOT`), writes to `outputs/<figure>/` and prints PASS/FAIL authority checks against
the values reported in the manuscript. Lightweight mode needs only `Source_Data.zip`,
`analysis_ready_data.zip` and `challenges_calibration_masks.zip`; raw mode additionally needs the
listed `raw_*.zip` archives and the commands in [REPRODUCIBILITY.md](REPRODUCIBILITY.md).
